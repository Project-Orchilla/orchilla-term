Orchilla API Documentation

Version 1.0 — Temporal and Semantic Processing

1. Endpoints

POST https://orchilla/recognize

Temporal Recognizer — detects temporal expressions within free text and returns their positions and type.

Request Body (JSON):

{
  "text": "We visited the family at Christmas in the year 2021."
}

Example Response:

{
  "entities": [
    [23, 46, "TEMP_EXP"]
  ]
}

Note: The indices indicate the start and end positions of the detected expression in the text.

POST https://orchilla/decompose

Semantic Decomposer — splits complex temporal expressions into atomic semantic units.

Request Body (JSON):

{
  "text": "the decade of the last 10s the decade of the next 50s in about three quarters of an hour"
}

Example Response:

{
  "entities": [
    [0, 28, "UNIT"],
    [29, 58, "UNIT"],
    [59, 87, "UNIT"]
  ]
}
POST https://orchilla/formalize

Formalizer — transforms atomic semantic units into formal DSL operations.

Request Body (JSON):

{
  "units": ["before", "half past 5"]
}

Example Response:

{
  "prediction": [
    { "operator": "before", "text": "before" },
    { "operator": "set", "text": "h05m30" }
  ]
}
POST https://orchilla/relate

Relation Classifier — determines which formal operations are related within a given context.

Request Body (JSON):

{
  "context": "temporal reasoning task",
  "operations": [
    { "operator": "before", "text": "h05m30" },
    { "operator": "after", "text": "h04m15" }
  ]
}

Example Response:

{
  "relations": [
    { "source": 0, "target": 1, "type": "TEMP_ORDER" }
  ]
}
